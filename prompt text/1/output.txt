**To start testing on your iPhone**
1. On your Mac, install Xcode 16 or newer and run `brew install xcodegen`. Then run `git clone https://github.com/OttomanLabsAI/Vocab-Folio.git`.
2. In the Firebase console, open Project settings → Your apps → **Add app → iOS**, with bundle ID `com.ottomanlabs.vocabfolio`. Download `GoogleService-Info.plist` into `ios/VocabFolio/`. Treat this step as required: without the file, the app falls back to the website's keys, and the iOS SDK may refuse those.
3. Run `cd Vocab-Folio/ios && xcodegen generate && open VocabFolio.xcodeproj`, then wait for Xcode to download the packages.
4. In the VocabFolio target, open Signing & Capabilities, turn on automatic signing, and pick your team. Do the same for VocabFolioTests.
5. On the iPhone, turn on Developer Mode (Settings → Privacy & Security → Developer Mode; the phone restarts). Plug it in, pick it as the run destination, and press ⌘R. You should see the language picker. Sign in with your website account and your words and progress load.
6. Press ⌘U to run the tests. One of them checks that the phone schedules reviews on exactly the same dates as the website.
7. For the student's phone, use TestFlight. Create the app in App Store Connect with the same bundle ID, then choose Product → Archive → Distribute → Upload. Once the build has processed, add them as a tester.
